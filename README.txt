LINK STASH - how to put it online (needs HTTPS)

Easiest free options (drag-and-drop the whole folder):
 - Netlify Drop:   https://app.netlify.com/drop
 - Cloudflare Pages / GitHub Pages also work.

Then open the web address on your phone:
 Android (Chrome): menu > Install app. After installing, Link Stash shows up in the Share menu.
 iPhone (Safari): Share > Add to Home Screen. (iOS does not support the Share menu entry.)

Your links are stored on the device. Use Export backup now and then.
If you change files later, edit sw.js and change link-stash-v1 to link-stash-v2 so phones update.
